# Guía del repositorio

- Mantén cada archivo de código fuente escrito a mano en un máximo de 250 líneas. Si crece más, extrae componentes, datos o lógica a archivos con una responsabilidad clara.
- Conserva las exportaciones y el comportamiento existente al refactorizar.
- Antes de subir cambios, ejecuta `npm run typecheck`, `npm run lint`, `npm test` y `npm run build`.
